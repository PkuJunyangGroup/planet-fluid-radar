SOURCES & METHODS

文献从哪里来

本站主要服务于北京大学物理学院大气与海洋科学系行星大气研究方向。以物理机制为线索，追踪全球相关研究，帮助组内成员发现值得阅读的新文献。

研究范围

筛选方向仅参考杨军、丁峰和 Daniel Koll 的公开研究主题：行星气候与宜居性、云和辐射反馈、水循环、热输送、环流、海冰与海洋过程，以及行星大气的观测表征。姓名不作为收录条件，也不设置个人论文专栏。

研究背景：杨军研究方向 · 丁峰公开研究资料 · Daniel Koll 研究方向 · 系内研究背景。

索引分为行星大气与气候、大气物理、大气与气候动力学、物理海洋与地球流体、系外行星探测与表征、行星内部与演化、表层过程与古气候、数学物理与数值方法。单篇文章可关联多个方向。

“大气物理”重点关注与上述研究相关的辐射传输、云微物理、水汽和凝结过程；“行星大气与气候”侧重行星环境、气候状态和宜居性。通过上下文词组约束筛选，并提供跨学科机制标签。目前为可解释的规则初筛，相关性仍需读者判断。

当前数据源

arXiv 是目前已接入的数据源，覆盖 astro-ph.EP、physics.ao-ph、physics.flu-dyn 和 physics.geo-ph。使用公开 API 查询近期更新，API 不可用时使用分类 RSS 获取当期公告。RSS 只能补充当前批次，不能证明历史记录完整。

Nature、Science 及其他期刊尚未接入。arXiv 预印本不等于已经过期刊同行评审，论文结论与正式发表信息请以原文为准。

三个日期，各有含义

字段含义
网站收录文献首次进入本站数据的日期，以北京时间显示。重复抓取、重新部署与修改标签均不重置此日期。
首次发布论文在 arXiv 首次提交发布的日期，来自原文页面或 API；不是期刊见刊日期，也不是 RSS 公告日期。
版本更新当前 arXiv 修订版本的提交时间；取得可核实记录时显示。

缺少可靠记录时显示“待核实”或“未记录”，不根据论文编号推算。首页时间筛选按网站收录时间计算。

双语导读与作者机构

现有文献的中英文简要导读由 AI 辅助依据公开摘要整理，帮助快速了解研究问题与方法，不代替原文。导读与文章版本、标题及摘要绑定；原文变化后旧导读不再自动沿用。

每日抓取无需 AI API 密钥。新增文献在中文导读整理前先显示英文摘要节选，并明确标注“中文导读待整理”；当前没有自动每日生成中文导读的服务。

机构信息提取自 arXiv 论文 HTML 的结构化作者与机构字段，并提供原文入口。只有明确的作者对应关系才展示配对；机构缺失不通过姓名或其他论文猜测。部分论文没有 HTML 或没有可解析字段，会显示“机构信息暂未获取”。

更新与维护

每日北京时间约 09:17 由 GitHub Actions 抓取并部署，任务可能排队延迟；以来源最后成功时间为准。抓取失败时保留已收录记录，公开显示状态，并在下次任务重试。管理员通过 GitHub 维护筛选规则。
